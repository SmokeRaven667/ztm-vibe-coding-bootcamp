# Module 1: Vibe Coding & Web Design

## Introduction

**Vibe coding is a new form of creative partnership.**

**Code writer** has encyclopedic memory and technical fluency. Write code line by line.

**Code director** has vision of what to build. They don't operate the camera, build the sets, and do the makeup. But they do the what and why as a directory. The AI is your creative partner.

Bottleneck is not typing speed or memory, but it's clarity, vision, and ability to communicate.
